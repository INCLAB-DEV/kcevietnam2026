# 매칭 단위는 Organization(기업)이며 Member(담당자)가 아님

매칭 알고리즘이 기업 단위로 동작하고, 미팅 참석자(Member)는 기업 내부에서 지정하는 구조로 결정했다. 방산 기업은 부서별로 다른 제품을 다루므로 담당자 단위 매칭도 고려했으나, 바이어 입장에서 신뢰 단위는 기업 브랜드이고 내부 담당자 배정은 기업의 판단 영역이다. 매칭 알고리즘 복잡도도 크게 줄어든다.

## Considered Options

- **Member 단위 매칭**: 담당자별 관심사/제품으로 매칭. 정밀하지만 매칭 알고리즘이 복잡해지고, 바이어에게 "기업 A 통신팀 김과장"을 노출하는 것이 부자연스러움.
- **Organization 단위 매칭 (채택)**: 기업 프로필과 키워드로 매칭. 미팅 수락 시 참석 Member를 지정. 알고리즘 단순, 바이어 신뢰도 높음.

## Consequences

- Member별 관심사/전문 분야를 별도로 수집할 필요 없음 (기업 프로필에 통합)
- 기업 내부에서 "이 미팅은 누가 나갈지" 결정하는 UI가 필요
