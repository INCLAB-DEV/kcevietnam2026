# AI 일괄 포화배정 정책

운영자가 **전체 참가사를 대상으로 AI 전체 포화배정**을 실행한다 — 빈 슬롯을 **참가사 우선으로 포화 배정**하되, **최소 N슬롯/참가사를 운영자가 설정**한다. 빈 슬롯을 품질 게이트 없이 최대한 채우되, 공급 비대칭(참가사 < 바이어) 때문에 양쪽을 동시에 "전부" 채울 수 없으므로 **참가사 슬롯을 우선 포화**시키고, 배정 경합은 **2라운드 + 비즈매칭 신청순 tie-break**으로 푼다.

**반복 실행 가능.** 1회성 액션이 아니다 — 신청기간(8/26~9/11) 마감 후 1차 실행이 가장 임팩트 크지만, 이후에도 운영자가 **언제든 재실행**할 수 있다(추가 전용·비파괴). 재실행 시 취소로 빈 슬롯·지각 합류 기업까지 흡수해 다시 포화시킨다.

## 배정 정책

- **참가사 우선 포화.** Exhibitor(103) < Buyer(178)라 참가사 슬롯이 먼저 동난다. 참가사가 성과측정 메인 타겟이므로 참가사 일정을 우선 채우고, 바이어는 남는 슬롯에서 Open으로 능동 선택.
- **2라운드 배정:**
  1. **보장 라운드** — 모든 참가사에 **최소 보장 슬롯 수**(운영자 설정 N, 기본 10)를 적합도 순으로 라운드로빈 → 0건 참가사 제거(효과 입증 최저선).
  2. **최적화 라운드** — 남은 슬롯은 전역 적합도 최대화로 채움.
- **tie-break(양 라운드 공통):** 경합 시 **비즈매칭 신청이 빠른 기업** 우선. 일찍 신청할 동기를 만들어 데이터 수집 목적과도 정렬.
- **추가 전용·비파괴.** 전체 포화배정은 재실행해도 기존 `accepted`/`proposed` 미팅을 이동·취소하지 않고 **현재 빈 슬롯만** 채운다. 따라서 취소로 생긴 빈 슬롯·지각 합류분은 **다음 포화배정 재실행**으로 보충된다(AI 자동 재충전은 아님 — 운영자가 트리거).
- **단일 기업 빈슬롯 보충(재트리거)** 은 별개 액션 — 한 기업만 골라 그 기업의 빈 슬롯을 보충한다(F-OP-003). 전체 대상은 위 전체 포화배정 재실행으로 처리.

## 수락 규칙 (ADR-0005)

전체 포화배정은 **"전원 즉시확정"이 아니다**(구버전의 유형-무관 예외 폐기). 운영자가 참가사 캘린더를 대신 채우는 구조이므로:

- **참가사 측: 자동확정** — 참가사는 미팅마다 일일이 수락하지 않는다(부담 제거가 원래 목적).
- **바이어 측: 유형별** — 초청 바이어(Hosted)=자동확정 / 일반 바이어=수락대기(`proposed`).
- 따라서 전체 포화배정에서 **수락대기는 일반 바이어 수신 건에만** 발생한다. (양방향 수락대기 없음)
- 운영자 Draft 검토 게이트는 유지(억지 매칭·노쇼 위험 거름) → 확정 시 위 규칙대로 양측에 배정/수락대기 통지.

## 운영 변수 (Organizer 설정)

운영 시작/종료 시각, 점심 블록, 슬롯 길이(기본 30분), **최소 보장 슬롯 수 N(기본 10)** 은 **하드코딩하지 않고 Organizer가 설정**한다. N은 전체 포화배정 **실행 시 입력 파라미터**로도 노출된다(실행마다 조정 가능). 일일 슬롯 수·총 슬롯 수·보장 가능 여부는 전부 이 변수에서 파생(F-MT-001의 "하루 18슬롯" 등 고정 수치는 디폴트 예시).

## 미팅 장소(룸) 배정 우선순위

1순위 선호는 바이어 동선 가까운 비즈니스 룸이나, 룸은 한정 자원(약 50개)이라 수요 초과 시: **① 초청 바이어(Hosted) 미팅 → ② 적합도 높은 미팅 → ③ 비즈매칭 신청 빠른 순**. 룸을 못 받으면 매칭존 테이블 → 참가사 부스로 폴백.

## 선행 의존성 (중요)

**적합도(fit score) 정의가 미해결**(키워드 카테고리 체계, CTO 협의 필요 — CONTEXT.md "Flagged ambiguities")이다. 보장/최적화 라운드와 룸 우선순위 모두 적합도 점수를 입력으로 쓰므로, **이 정의가 확정돼야 배정 엔진이 완성**된다.

## Considered Options

- **품질 게이트(적합도 임계값 이상만 배정, 나머지 빈칸):** 억지 매칭을 막지만 일부 슬롯이 비어 데모 임팩트·포화 목표가 약해짐. → 기각, 빈 슬롯 전부 채움 채택.
- **순수 적합도 그리디:** 인기 바이어가 소수 참가사에 몰려 일부 참가사 0건 → 효과 입증 실패. → 기각, 최소 보장 라운드로 형평성 확보.
