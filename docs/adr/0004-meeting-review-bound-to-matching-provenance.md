# 미팅 리뷰를 매칭 출처(provenance)와 결합 저장

미팅 리뷰가 NABI에 주는 가치는 두 가지다: **① 미팅 데이터 자산화**, **② 매칭 성과의 측정·입증**. 이를 위해 모든 미팅(Schedule Table 레코드)에 매칭 출처 메타 — `matching_type`(AI/Open/Forced/On-site), `ai_score`, `ai_score_reasons` — 를 **데이터 발생 시점에 영구 보존**하고, 리뷰 작성 시 수집한 **Fit Assessment(잘맞음/보통/안 맞음 + 자유 사유)**를 이 레코드에 결합한다.

이렇게 하면:
- **AI Matching**: `(ai_score, 실제 적합도)` 페어로 **precision을 측정**해 "우리 매칭이 예상 대비 얼마나 맞췄나"를 입증한다.
- **Open / On-site**: AI 점수가 없지만 대조군(control)이 된다 — "AI 추천군 vs 자율 발생군"의 적합도·전환율을 **준실험으로 비교**해 AI 매칭의 효과를 입증한다. 따라서 `matching_type`은 모든 리뷰의 1급 분석 축이다.

## 일회성 이벤트라는 전제 (중요)

DX Korea 2026은 **일회성 컨퍼런스**다. 같은 코호트가 다시 모이지 않으므로, 이 데이터의 목적은 **다음 매칭을 위한 학습/보정 루프가 아니라 성과의 측정·입증**이다. precision도 "다음에 더 잘하려고"가 아니라 "잘했다고 증명하려고" 잰다. 적합도 자유 사유 역시 매칭 피처 개선이 아니라 성과 분석·데이터 자산의 보조 재료다.

## 근거 / 트레이드오프

- 점수는 **사후 소급이 불가능**하다. 발생 시점에 박지 않으면 성과를 영영 측정할 수 없다.
- 비용은 레코드당 메타 몇 필드 + 리뷰 저장 시 결합 한 번. 측정·입증 능력 대비 무게가 작다.
- 결합 저장이 없으면 Fit Assessment는 어디에도 붙지 않는 고립된 숫자가 된다.

## 범위 경계

- **후속 전환의 "실거래 전환"은 9월 데모 시점엔 측정 불가** — 방산 거래는 전시 후 수개월. 9월엔 후속의향/러브콜까지만 잡고, 실거래 추적은 이후 과제.
- Fit Assessment·Follow-up Intent는 **비공개**(상대·NABI 한정), Love Call만 상대에게 보이는 신호. (CONTEXT.md 참조)
