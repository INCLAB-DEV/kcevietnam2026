## 2. ACT 1 — 참가사 온보딩 (3분) · ★강조: AI를 통한 데이터 프리필

> **페르소나**: 한지민, 28세, 에어빌리티(야간 감시 드론 전문). **목표**: 손 안 대고 프로필 완성 + 적합 바이어 매칭.

- **화면/URL**: `prototype-apply-seller.html` (허브 → "비즈매칭 신청" → 참가사(BM-002) "확인하기")
- **클릭**: 1단계 기본정보 — **회사명(에어빌리티 주식회사)·담당자(한지민) 프리필** 확인 → "입력 도우미" → **회사 자료 업로드 → 내용 분석 → 전시 품목 자동 추출** → 사업자번호로 **DART 자동 조회** → 완성도 바 상승
- **멘트**:
  > "참가사 입장에서 가장 귀찮은 건 정보를 일일이 입력하는 겁니다. NABI는 다릅니다. 회사명·담당자는 이미 채워져 있고, **회사 자료만 올리면 AI가 내용을 분석해 전시 품목과 매칭 키워드를 자동으로 뽑아냅니다.** 사업자번호를 넣으면 설립연도·직원수 같은 기업 정보는 DART에서 자동으로 가져옵니다. 담당자는 확인하고 다듬기만 하면 됩니다.
  > 그리고 '프로필을 채울수록 매칭률이 올라간다'는 완성도 바로 추가 정보를 유도합니다 — **정보가 많을수록 정확한 바이어가 붙으니까요.** 참가사의 수고는 줄이고, 우리가 가진 데이터는 늘린다. 이게 매칭 정확도의 출발점입니다."
- **포인트**: AI 프리필 = 참가사 진입장벽↓ + 데이터 자산↑. NABI의 핵심 자산은 데이터.

'무인체계·드론' 니즈에, **밀폐공간 점검이라는 특수 영역에서 독보적인 기술'** — 세계 최초 밀폐공간 비행 드론 ELIOS를 국내 독점 공급하는 회사입니다. 단순 키워드 매칭이 아니라 **왜 맞는지 이유까지** 보여주니까, 바이어는 큰 회사가 아니라 **자기 문제를 푸는 회사**를 찾을 수 있습니다. - **화면/URL**: `prototype-company-detail.html` (또는 discover 카드) — "미팅 신청" 클릭 시 **공유 모달(`nabi-meeting.js`)이 그 자리에서 열림** (별도 페이지 이동 없음)

- **멘트**:
  > "마음에 드는 기업에 **미팅을 신청**합니다. 가능한 시간을 고르면 — 상대와 겹치는 시간은 자동으로 빠집니다 — 장소만 정하면 끝. 요청이 한지민 님에게 전달됩니다."
- **포인트**: 탐색→즐겨찾기→미팅신청, 바이어가 능동적으로 세일즈 기회를 연다. 미팅 모달은 바이어·참가사·상세·탐색 어디서든 **같은 공유 컴포넌트**.

- **화면/URL**: `prototype-my-meetings.html` → **역할 토글 "참가사"** (우측 하단 dev 바)
- **클릭**: 참가사 뷰의 스케줄/요청 카드에서 **들어온 미팅 요청(한화시스템 바이어)** 선택 → 누가 신청했는지 확인 → **수락** (또는 거절)
- **멘트**:
  > "역할을 참가사로 바꿔보겠습니다. 한지민 님 화면입니다. 방금 한화시스템 바이어가 보낸 미팅 요청이 들어와 있습니다. 누가 신청했는지 확인하고 **수락**하면, 미팅이 확정됩니다. 거절도 한 번에 가능합니다. 신청→수락→확정, **거래 한 건이 이렇게 성사**됩니다 — 양쪽이 서로를 알고 만나는, 한 건의 세일즈 기회입니다."
- **포인트**: 바이어↔참가사 완전 대칭 + 거래 루프 완결(신청→수락→확정).
- ⚠️ **리허설 확인**: 참가사 역할 뷰에서 수락/거절 버튼이 뜨는 정확한 위치(스케줄 카드 클릭 → 상세 패널) 동선을 6/9 리허설에서 한 번 짚어둘 것. "바이어 브리핑(니즈 요약)" 화면은 현재 프로토타입에 없음 → 멘트에서 제외함.

## 5. ACT 4 — 숨은 바이어 발굴 (2분) · ★강조: 세일즈 기회 확대

> **페르소나**: David Chen, 38세, 싱가포르 국방부 조달관. 현장 등록 바이어(딥링크 로그인 인증, subtype `on_site`).
> **핵심**: 현장에서 합류하는 바이어를 온보딩해 미팅 기회를 부여 = 세일즈 풀 확장.

> ⚠️ **정책 변경(2026-07-02) — 이 액트는 갱신됨.** 미인증 게스트 탐색과 "미팅 신청 순간의 익명 Visitor→바이어 자기전환"은 폐지됐다. 서비스 페이지(기업 탐색·미팅)는 인증 전용이며 미인증 접근은 `/login`으로 리다이렉트된다. 이제 David는 현장에서 **딥링크 로그인(DX Korea 인증)으로 먼저 등록·인증**한 뒤 BM-001 프로필을 작성하고 미팅을 신청한다. 값 제안은 "익명 참관객 자동전환"이 아니라 **"현장 합류 바이어를 빠르게 온보딩·미팅 연결"**로 재프레이밍한다.

- **화면/URL**: `/login`(딥링크 로그인·DX Korea 인증) → `prototype-discover.html`(기업 탐색) → "미팅 신청" → `prototype-apply.html`(BM-001 프로필, **4단계**) → 완료 → `prototype-discover.html`(AI 추천 활성)
- **클릭**: 딥링크 로그인 → 기업 탐색에서 둘러보기 → "미팅 신청" → **프로필 작성(관심분야→상세니즈→예산/도입시기→완료, 4단계)** → 완료 화면 **"기업 탐색하러 가기"** → 기업 탐색·AI 추천으로 연결
- **멘트**:
  > "전시장에는 현장에서 합류하는 바이어가 많습니다. 그 안에 **진짜 바이어가 있죠.** NABI는 현장 등록(딥링크 로그인)으로 들어온 바이어도, **이 간단한 프로필 작성만으로** 매칭·미팅에 곧바로 연결합니다. 싱가포르 조달관 같은 해외 바이어도 — 언어는 AI가 자동 대응합니다.
  > 즉, 현장 합류 바이어를 **세일즈 기회로 바꾸는** 겁니다. 참가사 입장에선 미팅 기회가 늘어나는 거고요."
- **포인트**: 핵심 가치(세일즈) 극대화. 현장 등록 바이어 온보딩 → 미팅 연결 퍼널.
- ⚠️ **프로토타입 반영 필요**: 딥링크 로그인 후 apply 프로필은 **4단계**(등록 시 기본정보 프리필로 사용자 확인 단계 간소화 가능). 구버전의 "미인증 Visitor 모드·게스트 탐색·미팅 신청 시 자기전환"은 폐지 — 발표에선 로그인 → 기업 탐색(첫 화면) + 4단계 프로필 폼으로 개념 전달.

## 9. 예상 질문 & 답변 (Q&A)

**Q. 지금 AI가 실제로 도는 건가요?**
> 오늘은 컨셉 프로토타입으로, 응답은 대표 예시입니다. 실제 AI(Claude) 연동은 9월 실전 전까지 완료합니다.

**Q. AI 프리필은 어디서 데이터를 가져오나요?**
> 운영사 보유 명단 + 기업 공개 자료(웹사이트 등)를 바탕으로 초안을 채우고, 참가사가 확인·보정합니다. (DX코리아 DB 연동은 협의 중)

**Q. 매칭 정확도는 어떻게 보장하나요?**
> 1차 키워드 매칭 → 2차 AI 재순위화 + 추천 이유 생성. 데이터가 쌓일수록 정확도가 올라갑니다.

**Q. 방산 보안은요?**
> 민감 정보는 AI가 단정하지 않도록 제한하고, 가격 등은 "미팅에서 안내"로 유도합니다. 녹음·NFC는 보안 검토 후 단계적 도입.

**Q. 해외 바이어 언어는?**
> UI는 한국어 고정, AI 응답만 상대 언어를 자동 감지해 대응합니다.
