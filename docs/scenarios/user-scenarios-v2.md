## 시나리오 1: 바이어 비즈매칭 신청

> **페르소나**: 강시우 대위, 육군 제2군단 정보통신장교, 35세
> **역할**: Buyer (한화시스템 소속 Organization)
> **진입**: 운영사가 발송한 개인화 링크 이메일 수신
> **목표**: 비즈매칭 신청기간 내에 프로필을 작성하여 최적 매칭을 받을 준비

### 플로우

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|
| 1 | 이메일의 개인화 링크 클릭 | 랜딩 | "강시우님, 한화시스템 · 바이어" 인증 완료 표시 |
| 2 | "프로필 작성 시작" 탭 | BM-001 (1/3) | 관심 분야 키워드 선택 화면. 방산 대분류 14개 칩 |
| 3 | "무인기/드론", "감시/정찰", "센서/광학" 선택 | BM-001 (1/3) | 선택된 키워드 하이라이트. 넛지: "관심 분야를 많이 선택할수록 더 정확한 매칭을 받을 수 있습니다" |
| 4 | "다음" 탭 | BM-001 (2/3) | 상세 니즈 자유 텍스트 입력. 프로필 완성도 바 50% |
| 5 | "야간 감시가 가능한 소형 드론을 찾고 있습니다. 산악 지형에서 운용 가능하고, 적외선 카메라가 탑재된 제품. 예산 대당 5천만원 이내." 입력 | BM-001 (2/3) | 예산 범위, 도입 시기 선택 필드도 표시 |
| 6 | "AI 키워드 추출하기" 탭 | BM-001 (3/3) | AI 추출 키워드 표시: "소형 드론", "야간 감시", "적외선 카메라", "산악 운용", "ISR". 삭제/추가 가능. 프로필 완성도 85% |
| 7 | "ISR" 키워드에 "(정보·감시·정찰)" 설명 확인 | BM-001 (3/3) | 방산 전문용어 자연스럽게 노출 |
| 8 | "프로필 완성" 탭 | 완료 화면 | "비즈매칭 신청기간: 8/26~9/11. 신청기간 종료 후 매칭이 시작됩니다." 완성도 85%. "프로필 보강하기" CTA |
| 9 | (다음날) 앱 재접속 → 햄버거 → "내 프로필" | 프로필 | 키워드 확인, 완성도 바, "프로필 수정" 가능 |

### 핵심 포인트
- 개인화 링크 = 인증 완료. 별도 로그인/인증 없음
- 키워드 선택 → 자유 텍스트 → AI 추출 → 확인/보정 (3단계)
- 완성도 바 + 넛지로 추가 정보 입력 유도
- 매칭 결과는 신청기간 종료 후 — 즉시 나오지 않음
- 같은 Organization(한화시스템)의 다른 Member도 동일 링크 구조로 별도 프로필 작성 가능

## 시나리오 2: 참가사 비즈매칭 신청

> **페르소나**: 한지민, 에어빌리티 Senior Designer, 28세
> **역할**: Exhibitor (에어빌리티 Organization)
> **진입**: 운영사가 발송한 개인화 링크 이메일 수신
> **목표**: 기업 프로필을 보강하여 적합한 바이어와 매칭

### 플로우

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|
| 1 | 이메일의 개인화 링크 클릭 | 랜딩 | "한지민님, 에어빌리티 · 참가사" 인증 완료 표시 |
| 2 | "프로필 작성 시작" 탭 | BM-002 (1/2) | 기본 정보 프리필: 회사명(에어빌리티), 부스번호(A-127), 담당자(한지민). **빈 필드 하이라이트**: 전시 품목, 회사 소개 |
| 3 | 넛지 확인 | BM-002 (1/2) | "프로필을 채울수록 바이어 매칭률이 올라갑니다. 빈 항목을 채워주세요!" (경쟁심리 넛지). 프로필 완성도 35% |
| 4 | 전시 품목 입력: "야간 감시용 소형 드론 AERO-X1, 산악/도심 정찰 드론 AERO-S3" | BM-002 (1/2) | 빈 필드 하이라이트 해제 |
| 5 | 회사 소개 입력 | BM-002 (1/2) | 완성도 바 상승 |
| 6 | "다음: 키워드 설정" 탭 | BM-002 (2/2) | 분야 키워드 선택 + AI 추출 키워드 표시. "전시 품목과 회사 소개에서 추출했습니다." 완성도 75% |
| 7 | AI 추출 키워드 확인: "소형 드론", "야간 감시", "적외선 카메라", "정찰", "산악 운용" | BM-002 (2/2) | 삭제/추가 가능. "키워드를 보강하면 관련 바이어에게 더 많이 노출됩니다." |
| 8 | "프로필 완성" 탭 | 완료 화면 | "비즈매칭 신청기간 종료 후 바이어 매칭이 시작됩니다." 완성도 80%. "타겟 바이어 유형을 추가하면 매칭 정확도가 더 올라갑니다." |

### 핵심 포인트
- 엑셀 데이터 기반 프리필 — 빈 폼이 아니라 "다듬기"만 하면 됨
- 빈 필드 하이라이트 + 경쟁심리 넛지 → 자발적 정보 입력 유도
- 같은 Organization의 다른 Member(예: CTO)도 동일 기업 프로필에 기여
- 전시 품목/회사 소개에서 AI가 키워드 추출 → 입력 허들 낮춤

- AI가 제안, 수락/거절은 양측이 결정
- Open Matching(쌍방 자유 신청)과 AI Matching이 동일 화면에 표시
- 참가사도 바이어 리스트를 탐색하고 먼저 미팅 신청 가능 (능동적 바이어 발굴)
- 모든 매칭 결과는 Schedule Table에 기록
- 미팅 장소 선택 필수 (부스/매칭존/비즈룸)

- 상세보기에서 방산 전문용어 설명 자연스럽게 노출
- **참가사도 동일한 카드 기반으로 바이어를 탐색하고 미팅 신청 가능**
- 햄버거 메뉴: 참여자 탐색, 내 대화, 내 미팅, 매칭 제안, 내 프로필

## 시나리오 5: 현장 기업 탐색 — 채팅 기반 (플랜 A, 목표)

> **페르소나**: 강시우 대위 (Buyer, 로그인 상태)
> **시점**: 전시회 당일
> **전제**: 채팅 기반 서비스 품질이 검증되어 플랜 A 채택된 경우
> **참고**: ADR-0003 (채팅 vs 카드 상호 배타)

### 플로우

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|
| 1 | 앱 접속 | MN-001 NABI 대화 | "어떤 제품이나 기술에 관심이 있으신가요?" + 퀵태그(#드론감시, #통신장비, #사이버보안, #센서광학) |
| 2 | "야간에 감시할 수 있는 소형 드론을 찾고 있어요" 입력 | MN-001 | NABI 구체화 질문: "어떤 지형에서 운용하실 예정인가요?" + ISR 용어 설명 |
| 3 | "산악 지형이요. 적외선 카메라가 있으면 좋겠습니다." 입력 | MN-001 | "딱 맞는 기업 3곳을 찾았어요!" + 추천 카드 3개 인라인 삽입 (에어빌리티 92%, 드론시스텍 87%, 비전테크 78%) |
| 4 | 에어빌리티 카드 "대화하기 >" 탭 | AG-001 에이전트 채팅 | "안녕하세요! 에어빌리티입니다. 야간 감시용 소형 드론을 찾고 계시다고 들었어요." 바이어 맥락 자동 전달 |
| 5 | "적외선 카메라 성능이 어떻게 되나요?" | AG-001 | 상세 스펙 + 방산 용어 설명(VOx) 포함 응답 |
| 6 | "미팅 잡기" CTA 탭 | 장소 선택 | 장소 + 시간 슬롯 |
| 7 | 완료 | 미팅 완료 | Schedule Table 기록 |

### 핵심 포인트
- NABI 대화 2턴으로 니즈 파악 → 추천
- 추천 카드가 대화 안에 인라인 삽입 (별도 페이지 아님)
- 에이전트가 바이어 맥락을 이미 알고 있음 (NABI → 에이전트 맥락 전달)
- **참가사도 채팅 기반으로 바이어를 탐색하고 미팅 신청 가능**
- 카드 기반과 완전히 독립된 플로우 — 공존 불가

## 시나리오 6: 현장 등록 바이어 진입 + 미팅 신청

> ⚠️ **정책 변경(2026-07-02) — 이 시나리오는 갱신됨.** 미인증 게스트 탐색과 "Visitor→On-site Buyer 자기전환 게이트"는 폐지됐다. 서비스 페이지(기업 탐색·미팅)는 인증 전용이며, 미인증 접근은 라우트 가드로 `/login`으로 보내진다. David는 현장에서 **딥링크 로그인(DX Korea 인증)으로 먼저 인증**한 뒤 탐색·미팅을 진행한다(현장 바이어 subtype `on_site`은 생성하지 않음 — David는 명단 기준 바이어로 인증). 아래 "로그인 없이 둘러보기 → BM-001 전환"은 구버전 흐름이며, 인증 후 바이어 프로필 작성(BM-001)으로 대체해 읽는다.

> **페르소나**: David Chen, 싱가포르 국방부 조달관, 38세
> **역할**: 현장(On-site) 바이어 (현장 등록, 딥링크 로그인 인증)
> **진입**: 전시장 입구 QR코드 → 딥링크 로그인
> **목표**: 한국 방산 드론 기술 탐색, 관심 업체 미팅 신청

### 플로우

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|
| 1 | 전시장 입구 QR 스캔 → 딥링크 로그인(DX Korea 인증) | `/login` | "전시회에 오신 것을 환영합니다! 로그인 후 이용하실 수 있습니다." (게스트 탐색 없음 — 서비스는 인증 전용) |
| 2 | "기업 탐색 시작" 탭 | 참여자 탐색 | 검색 + 필터 + 103개 기업 카드 (바이어/참가사 동일 카드 UI) |
| 3 | 에어빌리티 "상세보기 >" 탭 | 상세보기 | 회사 소개, 전시 품목, 부스 위치. 방산 용어 설명 포함 |
| 4 | "미팅 신청하기" 탭 | BM-001 프로필 작성 | 안내: "미팅 신청을 위해 프로필을 먼저 작성해주세요." → BM-001 5단계 폼 (기본정보 입력 → 관심분야 → 상세니즈 → 예산/도입시기 → 완료) |
| 5 | BM-001 완료 → 미팅 신청 | MT-001 모달 | 장소 선택 → 시간 슬롯(양쪽 빈 슬롯 교집합) → AI 메시지 확인 → 전송 |
| 6 | "미팅 신청 완료" | 완료 | "상대방에게 미팅 요청을 보냈습니다. 이메일로 결과를 안내드립니다." |
| 7 | 햄버거 → "내 미팅" | 내 미팅 | 에어빌리티: 대기 중 |
| 8 | 다른 기업 탐색 → 미팅 추가 신청 | 참여자 탐색 | 동일 플로우 반복 |

### 핵심 포인트
- 딥링크 로그인(DX Korea) 인증 필요 — 게스트 탐색·자기전환 없음(2026-07-02 정책 변경)
- 미팅 신청 전 BM-001로 최소 정보 수집 (이름/소속/이메일 필수)
- 안내 문구로 정보 입력 이유 설명 → 이탈 방지
- 메뉴 간소화: 참여자 탐색 + 내 미팅 (2개만)
- On-site Matching으로 Schedule Table에 기록

## 시나리오 7: 운영사 현장 관리

> **페르소나**: 박수진, 운영사무국 PM, 40세
> **역할**: Organizer (최고관리자)
> **시점**: 비즈매칭 신청기간 + 전시회 당일

### Phase A: 비즈매칭 신청기간 (8/26~9/11)

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|
| 1 | 참가사/바이어 목록 관리 | OP-002 | 참가기업/바이어 탭. 프로필 조회/수정. DB 직접 입력으로 등록 |
| 2 | 매칭 설정 | OP-002 | 개별 우선 배정 + 스케줄 설정 (슬롯 시간, 최대 미팅 수) |
| 3 | 신청 현황 모니터링 | OP-001 대시보드 | 프로필 완성율, 신청자 수, 매칭 현황 집계 |
| 4 | 전체 비즈매칭 AI 실행 | OP-002 | AI 일괄 매칭 생성 (Draft → 검토 → 확정) → 양측에 알림 발송 |

### Phase B: 전시회 당일

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|
| 1 | 대시보드 확인 | OP-001 | 전체 활성도: 매칭 N건, 미팅 확정 N건, 대기 N건, 노쇼 N건 |
| 2 | 빈 슬롯 확인 → 강제 매칭 배정 | OP-005 | 바이어 선택 → 참가사 선택(AI 추천) → 빈 슬롯 교집합 → confirmed/proposed 선택 |
| 3 | 미팅 이행 확인 | OP-001 | Schedule Table 상태: 확정 → 완료/노쇼 업데이트 |
| 4 | 제한관리자(KOTRA)에게 일부 권한 부여 | 권한 관리 | sub 권한: 제한된 모니터링/관리 기능 |

### 핵심 포인트
- 최고관리자 / 제한관리자(sub) 2단계 권한
- 비즈매칭 신청기간: 목록 관리 + 링크 발송 + 현황 모니터링
- 전시회 당일: 대시보드(활성도 집계) + 강제 매칭 + 이행 확인
- 현장 측정 로드맵: 대시보드(6/17) → 이행확인(8/26) → NFC(추후)
