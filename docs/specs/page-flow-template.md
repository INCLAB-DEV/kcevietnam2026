# 페이지 플로우 탭 공통 구조

> 다음 세션에서 user-scenarios-v2.html 재구성 시 적용할 템플릿

## 각 페이지 플로우 탭에 포함할 항목

### 1. Page List (표)

| Page ID | 기능 ID | 페이지명 | 라우트 | 상태 | 비고 |
|---------|---------|---------|--------|------|------|
| BM-001 | F-BM-001 | 비즈매칭 프로필 작성 | /apply/buyer | draft | ... |

- page-list.csv와 동기화
- 해당 플로우에 관련된 페이지만 표시

### 2. 가설 / 목적 / 참고 / 관리지표

| 항목 | 내용 |
|------|------|
| **가설** | 이 페이지가 해결하려는 문제에 대한 가설. "~하면 ~할 것이다" |
| **목적** | 이 페이지의 존재 이유. 한 문장 |
| **참고** | 관련 ADR, 회의록, 프로토타입 링크 |
| **관리지표** | 이 페이지의 성공을 측정하는 KPI. 예: 프로필 완성율, 매칭 수락율 |

### 3. 단계별 행동 (flow-table)

기존과 동일한 테이블:

| 단계 | 행동 | 화면 | 시스템 반응 |
|------|------|------|------------|

**유형별 차이가 있는 경우:**
- 탭으로 분리 (바이어 / 참가사 / Visitor)
- 공통 단계는 한번만 표시, 분기점에서만 탭 전환

### 4. 핵심 포인트

기존과 동일 — 주요 설계 결정, 제약사항, 참고사항
