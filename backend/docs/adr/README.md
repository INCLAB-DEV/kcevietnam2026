# Backend ADRs

백엔드(FastAPI 도메인·데이터 레이어)에 **한정된** 아키텍처 결정만 여기 둔다.

- 시스템 전역·도메인·교차 레이어 결정 → 루트 `docs/adr/`
- 백엔드 고유 결정(예: 마이그레이션 전략, 엔드포인트 경계, 큐/잡 구조)이 실제로 확정될 때 `0001-*.md`부터 추가
- 작성 포맷은 루트 `docs/adr/`의 기존 ADR을 따른다

현재 등록된 백엔드 한정 ADR 없음. (DB 소유·Alembic·Cognito·S3 등 현 결정은 시스템 전역이라 루트 `docs/adr/0007`·`0008`에 있음)
