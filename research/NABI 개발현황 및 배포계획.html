NABI 개발 현황 및 배포 계획

2026. 9. 3.

1. 개발 완료된 기능

로그인 · 계정

  • 아이디/비밀번호 로그인, 회원가입, 로그아웃
  • 최초 로그인 시 약관 동의 절차를 거치고, 이후 역할(바이어·참가사·운영자)에 따라 첫 화면이 갈라짐

기업 탐색

  • 바이어에게는 참가사만, 참가사에게는 바이어만 보이는 교차 열람 규칙 적용
  • 기업 카드 목록과 상세 화면, 관심기업 담기
  • 한국어/영어 전환 시 기업명·소개·키워드까지 해당 언어로 표시. 영문이 없는 항목은 국문으로 대체 표시
  • 추천 탭 및 적합도 점수 노출 (점수 산출은 임시 로직, 2번 항목 참조)

미팅

  • 신청 3단계 구성: 시간 선택 → 장소 선택 → 신청 사유 확인
  • 양측 모두 비어 있는 30분 슬롯만 선택 가능. 점심시간과 참가사가 지정한 불가 시간은 자동 차단
  • 초청 바이어에게 보낸 신청은 즉시 확정, 그 외는 수락 대기 상태로 진입
  • 수락 / 거절(사유 입력) / 취소(사유 입력) 처리 완료
  • 같은 슬롯에 수락이 동시에 들어와도 한 건만 성립하도록 처리

홈 · 알림

  • 미팅 현황, 당일 일정, 알림으로 구성된 홈 화면
  • 앱 내 알림 생성, 상단 벨 안읽음 개수 표시, 알림함 목록

운영자 콘솔

  • 행사 기본정보와 운영시간·점심시간·슬롯 단위(분) 설정
  • 참가기업 목록 관리, 신청서 대리 작성, 엑셀 업로드 및 내려받기
  • 미팅 장소 등록, 통역사 등록 및 기업별 배정
  • 행사 전체 미팅 조회, 필요 시 강제 취소
  • 운영자 계정 부여·회수, 총괄/부분 권한별 접근 제한

서버 쪽은 끝났고 화면 연결만 남은 것

  • 미팅 리마인더 발송, 종료시각 경과 후 자동 완료 처리 스케줄러
  • 안내 메일 발송
  • 회의록 기능 (녹음 업로드, 자동 전사, AI 정리, PDF/워드 내려받기)

기타

  • 자동 테스트 백엔드 781건, 프런트 839건 전부 통과
  • macOS와 Windows 양쪽에서 구동 확인
  • 시연용 계정 8종(바이어·참가사·운영자)과 시나리오 데이터 준비 완료

2. 마무리해야 할 것

항목현재 상태
AI 매칭 추천 적합도 산출 기준이 아직 정해지지 않아 서버 계산 로직 없음. 현재 화면에 뜨는 점수는 임시 계산값. 기준 확정이 선행돼야 함
참가 신청서 승인 심사 제출까지는 되나 운영자 검토 후 승인/보완요청으로 되돌리는 절차 미구현
바이어 불가시간 등록 참가사만 지정 가능. 바이어 쪽 저장 기능 필요
상세 화면 단독 페이지 팝업으로 여는 경로는 실데이터 연동 완료. 별도 페이지로 여는 경로 일부가 아직 임시 화면
한/영 이중언어 화면 문구 일부와 기업 소개 등 본문 콘텐츠 번역 잔여
실 인증 연동 현재는 데모용 계정 체계로 동작. Cognito 및 DX Korea 인증 연결 작업 남음
메일·스케줄러·회의록 서버 기능은 완료. 사용자 화면에 붙이는 작업만 남음

운영 정책상 결정이 필요한 사항 3건. 미팅 거절 시 신청자에게 알림을 보낼지 여부, 응답 없이 방치된 신청의 만료 처리 방식, 같은 역할끼리 목록에 노출됐을 때 신청 허용 여부. 외 소소한 문구·표시 수정은 별도로 모아 처리 예정.

3. 향후 배포 계획

  • 현재는 개발용 PC에서만 구동 중이라 외부에서 접속할 수 없는 상태
  • AWS EC2 인스턴스에 백엔드(FastAPI)와 프런트(Next.js)를 올리고, 데이터는 RDS(PostgreSQL)로 이전
  • 첨부파일과 녹음 파일 저장은 S3, 로그인 인증은 Cognito 연동
  • 도메인 연결 및 HTTPS 적용 후 외부 접속 오픈
  • 오픈 전 데모 데이터를 실제 참가사·바이어 명단으로 교체
